# dev-backend

Backend development skills: multi-language backend engineering, idiomatic Go, MySQL patterns, and code review.

## Skills (4)

- **dev-backend** — Build robust backend systems with modern technologies (Node.js, Python, Go, Rust), frameworks (NestJS, FastAPI, Django), databases (PostgreSQL, MongoDB, Redis), APIs (REST, GraphQL, gRPC), authentication (OAuth 2.1, JWT), testing, security (OWASP Top 10), performance, scalability, DevOps (Docker, Kubernetes, CI/CD), and monitoring.
- **dev-golang** — Concurrent Go patterns with goroutines/channels, microservices with gRPC or REST, pprof performance optimization, and idiomatic Go with generics, interfaces, and robust error handling.
- **dev-mysql** — MySQL and MariaDB schema, query, indexing, transaction, replication, and connection-pool patterns for production backends, with on-demand topic references.
- **dev-code-review** — Two-axis review (Standards + Spec) of the changes since a fixed point, run in parallel sub-agents.

## Commands (4)

- `/dev-backend:backend` — Backend engineering guide: APIs, auth, databases, testing, security, performance, DevOps, and monitoring.
- `/dev-backend:go` — Idiomatic Go guide: concurrency, microservices, pprof performance, generics, interfaces, and testing.
- `/dev-backend:mysql` — MySQL/MariaDB patterns: schema, indexing, queries, transactions, pools, replication, security, and configuration.
- `/dev-backend:review` — Two-axis review (Standards + Spec) of the changes since a given commit, branch, or tag.
