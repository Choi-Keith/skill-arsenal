# /theme -- Theme Factory

Apply the `dev-theme-factory` skill to: $ARGUMENTS

Pick one of the 10 pre-set themes in the skill's `themes/` directory (arctic-frost, botanical-garden, desert-rose, forest-canopy, golden-hour, midnight-galaxy, modern-minimalist, ocean-depths, sunset-boulevard, tech-innovation) and apply its colors/fonts to the artifact — or generate a new theme on-the-fly. See `theme-showcase.pdf` for a visual preview of each theme.
