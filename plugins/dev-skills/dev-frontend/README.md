# dev-frontend

Frontend development skills: Ant Design, Next.js, artifact theming, and code review.

## Skills (4)

- **dev-antd** — Decision guide for antd 6.x, Ant Design Pro 5/ProComponents, Ant Design X v2, and the offline `@ant-design/cli`. (MIT, see `skills/dev-antd/LICENSE`)
- **dev-nextjs** — Expert in TypeScript, Node.js, Next.js App Router, React, Shadcn UI, Radix UI and Tailwind.
- **dev-theme-factory** — Toolkit for styling artifacts (slides, docs, landing pages) with 10 pre-set themes, or generate a new theme on-the-fly. (Apache-2.0, see `skills/dev-theme-factory/LICENSE.txt`)
- **dev-code-review** — Two-axis review (Standards + Spec) of the changes since a fixed point, run in parallel sub-agents.

## Commands (4)

- `/dev-frontend:antd` — Ant Design decision guide: component selection, theming/tokens, SSR, a11y, migration, local API lookup.
- `/dev-frontend:nextjs` — Next.js App Router guide: RSC boundaries, data fetching/caching, Server Actions, Shadcn/Radix/Tailwind.
- `/dev-frontend:theme` — Style an artifact with one of 10 pre-set themes, or generate a new theme on-the-fly.
- `/dev-frontend:review` — Two-axis review (Standards + Spec) of the changes since a given commit, branch, or tag.
