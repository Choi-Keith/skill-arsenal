# /private-company -- 未上市公司研究

Apply the **finance-private-company-research** skill to: $ARGUMENTS

## Invocation

```
/finance-research:private-company 蚂蚁集团
/finance-research:private-company SpaceX
```

## Notes

- 专为蚂蚁集团、小红书、SpaceX、Stripe 等未上市公司设计
- 目标不是市场给的估值，而是生意本身值多少钱；信息稀缺条件下须明确标注置信度
