# /team -- 投研团队并行研究

Apply the **finance-investment-team** skill to: $ARGUMENTS

## Invocation

```
/finance-research:team 腾讯
/finance-research:team NVDA
```

## Notes

- 与 `/finance-research:company` 的区别：本命令创建真正的多Agent并行团队，适合需要多视角交叉验证的深度研究
- 财务数据必须遵循 **finance-financial-data** 规范：两个独立来源，误差>1%须标记
