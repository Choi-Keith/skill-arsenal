# finance-research

公司投资研究插件：从行业到个股、从管理层到未上市公司，外加财务数据规范与段永平问答。

## Skills (8)

- **finance-investment-research** — 巴菲特-芒格-段永平-李录四大师综合分析框架。
- **finance-investment-team** — 四角色并行分析框架，使用 Team 工具创建多Agent并行研究团队。
- **finance-industry-research** — 产业链全景扫描 + 四大师个股分析框架。
- **finance-management-deep-dive** — 管理层纵深研究：买股票就是买人。
- **finance-private-company-research** — 未上市公司多Agent并行深度研究框架。
- **finance-income-investment** — 分红收入的可持续性与组合角色分析。
- **finance-dyp-ask** — 扮演段永平本人，以他的方式思考并回答问题。
- **finance-financial-data** — 财务数据获取与交叉验证规范（其他 finance 命令共用）。

## Commands (8)

- `/finance-research:company` — 四大师综合投资研究。
- `/finance-research:team` — 投研团队并行研究。
- `/finance-research:industry` — 行业投资研究。
- `/finance-research:management` — 管理层纵深研究。
- `/finance-research:private-company` — 未上市公司研究。
- `/finance-research:income` — Income investment 分析。
- `/finance-research:ask-dyp` — 段永平问答。
- `/finance-research:data-rules` — 财务数据交叉验证规范。
