# /funnel -- 行业漏斗筛选

Apply the **finance-industry-funnel** skill to: $ARGUMENTS

## Invocation

```
/finance-screening:funnel 固态电池
/finance-screening:funnel 创新药
```

## Notes

- 先用 `/finance-research:industry` 看清产业链格局，再用本命令精选标的，两者互补
- 漏斗产出后可接 `/finance-screening:checklist` 做买入前系统检查
- 财务数据必须遵循 **finance-financial-data** 规范：两个独立来源，误差>1%须标记
