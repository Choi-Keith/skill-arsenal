# finance-screening

选股筛选插件：从全市场漏斗到买入前检查。

## Skills (4)

- **finance-industry-funnel** — 漏斗式价值投资筛选，从全市场逐层精选到 3 家。
- **finance-quality-screen** — 7条去劣指标，快速排除非一流公司。
- **finance-investment-checklist** — 巴菲特价值投资买入前 Checklist。
- **finance-bottleneck-hunter** — AI驱动的全球产业链瓶颈扫描与套利机会挖掘。

## Commands (4)

- `/finance-screening:funnel` — 行业漏斗筛选。
- `/finance-screening:quality` — 去劣指标筛选。
- `/finance-screening:checklist` — 巴菲特买入前 Checklist。
- `/finance-screening:bottleneck` — 供应链瓶颈猎手。
