# finance-portfolio

投后与组合管理插件：买入后的纪律系统。

## Skills (4)

- **finance-portfolio-review** — 投资组合审视与优化。
- **finance-thesis-tracker** — 投资论文追踪：建立并追踪核心假设、红线与估值锚点。
- **finance-thesis-drift** — 投资论文漂移检测：分清事实变化与措辞变化。
- **finance-news-pulse** — 股价异动快速归因：4 个并行 Agent 侦察事件/政策/对手/情绪。

## Commands (4)

- `/finance-portfolio:review` — 投资组合审视。
- `/finance-portfolio:track` — 投资论文追踪。
- `/finance-portfolio:drift` — 投资论文漂移检测。
- `/finance-portfolio:news` — 公司新闻脉搏。
