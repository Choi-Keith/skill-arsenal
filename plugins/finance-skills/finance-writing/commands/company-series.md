# /company-series -- 深度公司系列

Apply the **finance-deep-company-series** skill to: $ARGUMENTS

## Invocation

```
/finance-writing:company-series 腾讯
/finance-writing:company-series 拼多多
```

## Notes

- 产出 3-8 篇《看懂XX》系列长文（按公司复杂度定），发布在公众号/视频号等公开渠道
- 核心 IP 不是"会写"而是"会改"：严格执行 skill 内置的事实核查标准
- 不适合单篇研报、季报点评、行业研究——那些用 `/finance-research:company`、`/finance-earnings:review`、`/finance-research:industry`
- 可先用 `/finance-research:team` 或 `/finance-research:company` 生成内部研究底稿
